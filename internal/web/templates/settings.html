Settings

Polling cadence

How often each creator's profile is checked for new posts. Per-creator overrides are configurable on the creator detail page (planned).

Self-curating library

After the grace window, videos move to "archived" — media file removed, but title, description, summary, transcript, tags, and thumbnail are kept so you can review history and re-download. Metadata TTL caps how long archived rows linger before they're hard-purged. Set to 0 to keep history forever; storage cost is roughly 35–40 KB per archived row.
